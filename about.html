🛡️ Protegiendo conductores

Tu combustible, nuestra prioridad

FuelWatch Bolivia es una plataforma colaborativa que permite a los conductores reportar y consultar la calidad del combustible en estaciones de servicio, previniendo daños mecánicos causados por gasolina adulterada.

Ir al Dashboard →
01

El Problema

⛽

Combustible Adulterado

En Bolivia, miles de conductores enfrentan el riesgo de cargar combustible de baja calidad que puede dañar el motor de sus vehículos.

🔧

Reparaciones Costosas

Los daños por combustible adulterado generan gastos de reparación que pueden superar los miles de bolivianos.

🤷

Sin Información

Actualmente no existe un sistema público donde los conductores puedan consultar reportes sobre la calidad del combustible por surtidor.

02

Nuestra Solución

FuelWatch Bolivia funciona como un sistema de crowdsourcing: los mismos conductores alimentan la base de datos con sus experiencias reales después de cargar combustible.

1

Registra tu carga

Ingresa el nombre del surtidor y la fecha de tu recarga. El estado se marca como Operable por defecto.

2

Monitorea tu vehículo

Observa el comportamiento de tu vehículo durante los días siguientes a la carga de combustible.

3

Reporta si hay fallas

Si detectas problemas, actualiza tu reporte a "Falla detectada". Esto alerta a otros conductores.

4

Consulta antes de cargar

Revisa el dashboard antes de ir a un surtidor. Los surtidores con múltiples fallas se marcan con alertas visibles.

03

Arquitectura Cloud

El sistema utiliza una arquitectura 100% Serverless, sin necesidad de administrar servidores propios.

🌐

Frontend — Vercel

Hosting con despliegue continuo (CI/CD) conectado a GitHub.

🗄️

Backend — Supabase

Base de datos PostgreSQL con API REST automática (BaaS).

⚡

Bundler — Vite

Desarrollo rápido con HMR y build optimizado para producción.
